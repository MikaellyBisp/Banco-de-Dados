# Controle de Acesso

Página web desenvolvida para visualizar e organizar registros de acesso de usuários a um site, apresentando informações como identificação, nome, data, horário de entrada, horário de saída e status.

## Sobre o projeto

O **Controle de Acesso** é um projeto desenvolvido com HTML, CSS e JavaScript, utilizando jQuery e a biblioteca DataTables para exibir os registros em formato de tabela.

O objetivo é facilitar a consulta dos acessos registrados, permitindo visualizar informações dos usuários e servir como base para a implementação de filtros de pesquisa.

## Funcionalidades

- Exibição dos registros de acesso em uma tabela.
- Identificação dos usuários por ID e nome.
- Visualização da data do acesso.
- Exibição dos horários de entrada e saída.
- Campo para apresentação do status do acesso.
- Integração com a biblioteca DataTables.

## Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** estilização da interface.
- **JavaScript:** funcionalidades e interatividade.
- **jQuery:** manipulação dos elementos da página.
- **DataTables:** organização e interação com os dados da tabela.

## Como executar o projeto

1. Abra a pasta do projeto no Visual Studio Code.
2. Verifique se as bibliotecas jQuery e DataTables estão nos caminhos referenciados no código.
3. Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão Live Server do VS Code.
